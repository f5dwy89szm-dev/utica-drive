# Kingdoms of Ember

An original mobile real-time strategy prototype inspired by classic empire-building games.

## First playable slice
- Procedural battlefield and settlement
- Resource counters
- Trainable villagers
- Select-and-move touch controls
- Enemy raider patrol
- Mobile-friendly HUD

Open the project with Unity 6, create an empty scene, add it to Build Settings, and press Play. The runtime bootstrap creates the game automatically.

Branch: `kingdoms-mobile-rts`
