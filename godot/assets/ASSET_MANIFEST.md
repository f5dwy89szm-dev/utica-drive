# Utica Drive asset manifest

The Godot rebuild uses these slots for original, licensed assets. Place files in
the matching folders and the scene loader can replace the temporary geometry:

- `vehicles/player_bmw_m4.glb` — BMW-inspired performance coupe, human-scale.
- `vehicles/traffic_sedan.glb` — modern sedan.
- `vehicles/traffic_suv.glb` — modern SUV.
- `vehicles/traffic_van.glb` — utility van.
- `characters/player.glb` — rigged third-person character.
- `characters/pedestrian_01.glb` — pedestrian variation.
- `materials/asphalt_albedo.png` / `asphalt_roughness.png` — road PBR maps.
- `materials/concrete_albedo.png` / `concrete_roughness.png` — sidewalk PBR maps.
- `materials/brick_albedo.png` / `brick_roughness.png` — Utica brick façades.
- `materials/grass_albedo.png` / `grass_roughness.png` — northern New York terrain.

Use only assets with redistribution rights. The project does not copy Rockstar
characters, models, textures, or code.
